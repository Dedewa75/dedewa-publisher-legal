Politique de confidentialité

Dernière mise à jour : 14 novembre 2026

1. Principe

Dedewa Publisher fonctionne localement sur l'ordinateur Windows de l'utilisateur. Aucune donnée n'est vendue, partagée à des fins publicitaires ou envoyée vers un serveur appartenant à l'éditeur.

2. Données reçues de TikTok

Avec l'autorisation de l'utilisateur, l'application reçoit via les API officielles de TikTok :

  • les informations de profil de base (identifiant, nom affiché, avatar, lien de profil, biographie, statut vérifié) ;
  • les statistiques du compte (abonnés, abonnements, likes, nombre de vidéos) ;
  • la liste des vidéos publiques et leurs statistiques (vues, likes, commentaires, partages).

3. Utilisation

Ces données servent uniquement à afficher le profil et les statistiques dans l'application, à comparer les performances des vidéos et à améliorer les recommandations d'horaires de publication pour l'utilisateur lui-même.

4. Vidéos

Les vidéos restent dans les dossiers choisis par l'utilisateur. Leur analyse (image et son) est effectuée sur son ordinateur. Une vidéo n'est transmise qu'à TikTok, uniquement lorsque l'utilisateur l'a marquée comme prête, pour être déposée en brouillon dans son compte.

5. Stockage et sécurité

Les données sont stockées sur l'ordinateur de l'utilisateur. Les jetons d'accès TikTok sont chiffrés et ne sont jamais enregistrés en clair.

6. Suppression

L'utilisateur peut à tout moment déconnecter un compte TikTok dans l'application, ce qui supprime les jetons associés, ou révoquer l'accès depuis les paramètres de son compte TikTok. La désinstallation de l'application supprime les données locales.

7. Tiers

Les seules communications externes ont lieu avec les API officielles de TikTok, soumises à la Politique de confidentialité de TikTok.

8. Contact

Pour toute question : github.com/Dedewa75.
